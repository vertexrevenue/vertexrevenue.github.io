# Vertex Revenue

Pre-qualified sales calls for US agencies and consultancies.

Live site: https://vertexrevenue.github.io

## What is in this repo

| Path | What it is |
|---|---|
| `website/` | The source code of the site (Vite, React, Three.js). Edit here. |
| `.github/workflows/deploy.yml` | Builds `website/` on every push to `main` and publishes the result. |
| `index.html`, `privacy.html`, `terms.html`, `founder.webp`, `favicon.svg`, `assets/` | The built site that GitHub Pages serves. Generated by the workflow. Do not edit by hand, changes are overwritten. |

Read `website/README.md` for how to change text, prices and links.

## How a change goes live

1. Change a file inside `website/`.
2. Push to `main`.
3. The "Build website" workflow runs, then GitHub Pages publishes. About 2 minutes.

Check progress in the Actions tab. A green tick on both "Build website" and "pages build and deployment" means it is live. Hard refresh the browser (Ctrl+Shift+R) to see it.

## Rules for this site

- No fake clients, logos, testimonials or numbers. The sample call brief is labelled as illustrative.
- Promises on the site must be true: $500 a month, month-to-month, a call that misses a check is replaced, a report every Friday.
- Never delete `website/`. It is the only copy of the source.

Private working files (business context, sender script) are kept out of this repo on purpose.
